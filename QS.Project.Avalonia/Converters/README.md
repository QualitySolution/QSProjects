# Конвертеры Avalonia

Конвертеры в этой папке являются частью слоя представления Avalonia и реализуют
`Avalonia.Data.Converters.IValueConverter`.

В GTK-стеке используется другой интерфейс — `Gamma.Binding.IValueConverter`.
Несмотря на похожие сигнатуры методов, это разные и невзаимозаменяемые типы.
Кроме того, некоторые конвертеры возвращают специфичные для Avalonia объекты,
например `Bitmap` или `ITransform`.

Поэтому эти реализации должны оставаться в GUI-специфичном проекте
`QS.Project.Avalonia`, а не переноситься в `QS.Project.Desktop`. Если у
конвертеров появляется общая нетривиальная логика, в общий проект следует
выносить только эту UI-независимую логику, оставляя здесь адаптер для Avalonia.

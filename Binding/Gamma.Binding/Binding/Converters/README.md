# Конвертеры GTK binding

Конвертеры в этой папке относятся к GTK-стеку привязок и реализуют
`Gamma.Binding.IValueConverter`.

В Avalonia используется другой интерфейс —
`Avalonia.Data.Converters.IValueConverter`. Несмотря на похожие сигнатуры
методов, это разные и невзаимозаменяемые типы. Сам проект `Gamma.Binding` также
связан с GTK и использует GTK-специфичные типы в части своих конвертеров.

Поэтому эти реализации должны оставаться в GUI-специфичном binding-слое, а не
переноситься в `QS.Project.Desktop`. Если у GTK- и Avalonia-конвертеров
появляется общая нетривиальная логика, в общий проект следует выносить только
эту UI-независимую логику, оставляя отдельные адаптеры для каждого GUI.
